# Portofolio Mahasiswa Teknik Informatika

Website portofolio mahasiswa Teknik Informatika yang menampilkan informasi profil, kompetensi teknis, proyek, pengalaman organisasi, kontak, dan link GitHub.

## Fitur

- Profil mahasiswa
- Kompetensi teknis
- Daftar proyek
- Pengalaman organisasi
- Informasi kontak
- Link GitHub

## Teknologi yang Digunakan

- HTML5
- CSS3
- Git
- GitHub

## Struktur Halaman

Website terdiri dari beberapa bagian utama:

1. Home
2. Profil
3. Kompetensi Teknis
4. Daftar Proyek
5. Pengalaman Organisasi
6. Kontak

## Cara Menjalankan

1. Clone repository.
2. Buka folder project.
3. Jalankan file `index.html` menggunakan browser.

## Publikasi

Website dapat dipublikasikan sebagai website statis menggunakan GitHub Pages.
